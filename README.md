JINIPAY NodeJS USSD API 
========================
The [Node.JS](http://nodejs.org) library for [JINIPAY (jinipay.co)](https://jinipay.co)

## Platform proposal

The proposed direction for AfriPay is a unified integration platform for African
payment, KYC, banking, and telecom providers. Read the
[platform blueprint](docs/platform-blueprint.md) for the proposed MVP,
architecture, delivery milestones, and decisions still to resolve. This is a
design proposal; the SDK below does not implement these platform capabilities.
